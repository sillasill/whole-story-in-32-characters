A Wi-Fi network name of 22 characters that lands a joke and implies a whole story — a breakup, a changed password, and someone locked out of their own network — in the few words a phone shows in its network list. The joke lands on the first read, with no setup and no explanation.

## Run it

```sh
node main.ts
```

Writes the name to `/output/entry.txt`.
